## Waiver Content

```markdown
# B4 EV Authenticode Waiver — Stage 12

## Waiver ID
WAIVER-B4-2026-09-16

## Requirement Waived
EV Authenticode Code Signing Certificate for Windows binary (`aether.exe`)

## Justification
No EV certificate has been procured. Procurement requires:
- Organizational identity validation (3-5 business days)
- Hardware token delivery (7-14 business days)
- Certificate issuance (1-2 business days)
- Total timeline: 2-3 weeks minimum

No budget allocation or procurement initiation has occurred.

## Risk Assessment
| Risk | Likelihood | Impact | Mitigation |
|------|------------|--------|------------|
| SmartScreen warnings on Windows | HIGH | MEDIUM | Document as known limitation; users must explicitly allow |
| Enterprise policy rejection | MEDIUM | HIGH | Restrict Windows distribution to expert/internal use only |
| Supply chain trust reduction | LOW | MEDIUM | Cosign keyless signing for Linux/macOS; checksums + SBOM for all |

## Affected Artifacts
- `aether_windows_amd64.exe` (all Windows releases)
- No impact on Linux/macOS binaries (cosign keyless signing available)

## Compensating Controls
1. **Cosign keyless signing** for Linux/macOS artifacts (implemented in CI)
2. **SHA-256 checksums** published and verified for all artifacts
3. **SBOM (SPDX)** generated for all artifacts
4. **Provenance** (to be implemented in Stage 12 Phase 6)
4. **VERIFY.md** with independent reproduction steps
5. **Explicit documentation** in release notes: "Windows binary unsigned — SmartScreen warnings expected"

## Expiry Date
**2027-03-31** (as mandated by Stage 11 requirement)

## Owner
Release Engineering Lead

## Approval Authority
Required: Security Lead + Engineering Director

## Revalidation Trigger
- EV certificate procured and configured
- OR expiry date reached (waiver must be renewed or GA blocked)

## Explicit Statement
> This waiver does **not** constitute implementation. The EV Authenticode requirement remains mandatory for GA. This waiver permits RC2 release with explicit limitation documentation only.
```
