# B4 EV Authenticode Waiver — Stage 12 (Formal)

**Waiver ID:** WAIVER-B4-2026-09-16
**Date:** 2026-09-16
**Status:** SUBMITTED FOR APPROVAL

---

## Requirement Waived

**EV Authenticode Code Signing Certificate** for Windows binary (`aether.exe`) in all release artifacts.

---

## Justification

No EV certificate has been procured. The procurement process requires:
1. Organizational identity validation (3-5 business days)
2. Hardware token delivery (7-14 business days)
3. Certificate issuance (1-2 business days)
4. CI/CD integration and testing (2-3 business days)

**Total minimum timeline: 2-3 weeks**

No budget allocation, procurement initiation, or vendor selection has occurred to date.

## Compensating Controls (Implemented or Planned)

1. **Cosign keyless signing** — Linux/macOS artifacts signed in CI workflow
2. **SHA-256 checksums** — Generated for all 4 platform artifacts + SBOMs
3. **SBOM (SPDX 2.3)** — Generated via syft for all artifacts
4. **Provenance** — SLSA-style provenance to be implemented in Stage 12 Phase 6
5. **VERIFY.md** — Independent reproduction guide to be published
6. **Release notes disclosure** — Explicit "Windows binary unsigned" notice
