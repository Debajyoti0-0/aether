## Potential Causes for CI-Local Discrepancy

### 1. Flaky Test (Timing/Concurrency)
- Tests with `time.Sleep`, `time.After`, or channel operations
- `TestPublishUnsubscribeRace` uses 100 goroutines — could be timing-sensitive
- Network-based tests (Teamserver dial/accept)

### 2. Resource Exhaustion
- CI runner has limited CPU/memory (2 vCPU, 7GB RAM)
- 100 concurrent goroutines in race test + other tests
- File descriptor limits

### 3. Test Isolation Issues
- Tests sharing global state (maps, singletons)
- Workspace tests creating files in system temp
- PKI generation in tests

### 4. Go Version Differences
- CI: `1.27.x` (could be 1.27.0, 1.27.1, etc.)
- Local: `1.27.1` (exact)
- Minor version differences in runtime/test behavior

### 5. Dependency Resolution
- CI: Fresh module download each run
- Local: Cached modules
- Possible version mismatch in transitive deps

### 6. Filesystem Differences
- Linux (CI) vs Windows (local) — case sensitivity, path separators
- Tests using `filepath.Join`, `os.MkdirAll`, temp files
