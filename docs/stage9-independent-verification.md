## 3. Reproduction Steps

### Step 1: Clone and Checkout
```bash
git clone https://github.com/Debajyoti0-0/aether.git
cd aether
git checkout v4.0.0-rc1  # or the actual release tag
```

### Step 2: Verify Source Integrity
```bash
# Verify version consistency
cat VERSION                    # Should match tag (v4.0.0-rc1)
git describe --tags --exact-match  # Should match tag
go run ./cmd/aether --version  # Should match VERSION
```

### Step 3: Build Artifacts
```bash
# Local build (reproducibility test)
go build -ldflags="-s -w -X github.com/Debajyoti0-0/aether/internal/version.Version=$(cat VERSION) -X github.com/Debajyoti0-0/aether/internal/version.Commit=$(git rev-parse HEAD)" -o aether-local ./cmd/aether

# Or use GoReleaser for full matrix
goreleaser release --snapshot --clean
```

### Step 4: Verify Checksums
```bash
# From GoReleaser output
sha256sum -c dist/checksums.txt
# All 4 platform artifacts must PASS
```

### Step 5: Verify SBOM
```bash
# If generated by CI
jq -e '.specVersion' dist/sbom-cyclonedx.json
jq '.components | length' dist/sbom-cyclonedx.json
# Verify corresponds to binary
syft dist/aether_4.0.0-rc1_linux_amd64.tar.gz -o cyclonedx-json | jq -e '.specVersion'
```

### Step 6: Verify Provenance
```bash
jq -e '.buildType' dist/provenance.json
jq -e '.builder.id' dist/provenance.json
jq -e '.subject[] | select(.name | test("aether_"))' dist/provenance.json
```

### Step 7: Verify Signatures
```bash
# Linux/macOS (cosign keyless)
cosign verify-blob --signature dist/aether_4.0.0-rc1_linux_amd64.tar.gz.sig \
  --certificate dist/aether_4.0.0-rc1_linux_amd64.tar.gz.pem \
  --certificate-identity-regexp ".*" \
  --certificate-oidc-issuer-regexp ".*" \
  dist/aether_4.0.0-rc1_linux_amd64.tar.gz

# Windows (Authenticode) - requires Windows
signtool verify /pa /v dist/aether_4.0.0-rc1_windows_amd64.exe

# Manifest/SBOM/Checksums
cosign verify-blob --signature dist/release-manifest.json.sig \
  --certificate dist/release-manifest.json.pem \
  --certificate-identity-regexp ".*" \
  --certificate-oidc-issuer-regexp ".*" \
  dist/release-manifest.json
```

### Step 8: Run Test Suite
```bash
go test -count=1 ./...
go test -tags=integration -count=1 ./test/integration/...
```

### Step 9: Tamper Detection
```bash
# Test 1: Modified binary fails checksum
cp dist/aether_4.0.0-rc1_linux_amd64.tar.gz dist/aether_4.0.0-rc1_linux_amd64.tar.gz.tamper
echo "x" >> dist/aether_4.0.0-rc1_linux_amd64.tar.gz.tamper
sha256sum -c dist/checksums.txt 2>&1 | grep -q "FAILED" && echo "PASS: Tampered binary rejected"

# Test 2: Modified manifest fails signature
cp dist/release-manifest.json dist/release-manifest.json.tamper
jq '.version = "9.9.9"' dist/release-manifest.json.tamper > dist/release-manifest.json.tamper2 && mv dist/release-manifest.json.tamper2 dist/release-manifest.json.tamper
cosign verify-blob --signature dist/release-manifest.json.sig --certificate dist/release-manifest.json.pem dist/release-manifest.json.tamper 2>&1 | grep -q "verification failed" && echo "PASS: Tampered manifest rejected"

# Test 3: Modified SBOM fails signature
# Test 4: Modified checksums fail
# ... (all 9 tamper tests)
```
