### Thread Safety (Code Review)
- `sync.RWMutex` protects all shared fields
- `loadVersions()` uses write lock
- `GetKeyVersion()` uses read lock (with fallback to loadVersions under write lock)
- `RotateKey()` uses write lock for state update, then calls loadVersions
- `ListKeyVersions()` uses read lock after loadVersions
- `Close()` uses write lock
