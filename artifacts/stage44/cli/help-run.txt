Run the Aether kill chain in sequence: CAP bypass evaluation →
path validation → SOC signal prediction → engagement report.
Each phase is gated by the operator risk ceiling and paced by
--low-slow jitter when enabled.

Usage:
  aether run [flags]
  aether run [command]

Available Commands:
  plan        Execute an adaptive DAG plan (JSON) with fallbacks and retries

Flags:
      --auto                 Autonomous mode: continue past risk gates, use stored PRT
      --behavior string      Behavior mode: realistic (human pacing) or empty (fast)
      --bh-json string       BloodHound path JSON (optional)
  -h, --help                 help for run
      --low-slow             Randomize 1-5s jitter between phases
      --persona string       Persona for realistic behavior: engineer, hr, executive, analyst (default "engineer")
      --policies string      CAP export JSON (optional)
      --prt-file string      PRT JSON to convert in the chain (optional; auto mode uses the stored PRT)
      --respect-hours        Delay execution until the persona's active window
      --risk-threshold int   Risk ceiling 0-100 (default 50)
      --seed int             Deterministic seed for behavior engine (-1 = random) (default -1)
      --workspace string     Workspace name (required)

Global Flags:
      --config string      Config file path
      --log-level string   Log level (debug, info, warn, error) (default "info")

Use "aether run [command] --help" for more information about a command.
