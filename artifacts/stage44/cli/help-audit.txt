Tamper-evident audit trail (signed hash chain)

Usage:
  aether audit [command]

Available Commands:
  record      Record a command into the signed audit chain
  verify      Verify the workspace audit chain integrity

Flags:
  -h, --help   help for audit

Global Flags:
      --config string      Config file path
      --log-level string   Log level (debug, info, warn, error) (default "info")

Use "aether audit [command] --help" for more information about a command.
