Build and execute a live identity graph across Entra ID, AWS, and GCP.

Usage:
  aether graph [command]

Available Commands:
  build       Build the identity graph from exports or live Graph
  correlate   Discover cross-cloud attack paths (Entra → AWS → GCP)
  generate    Auto-generate a DAG plan from a graph path
  qualify     Qualify a node path into an executable runbook
  stats       Show graph statistics
  visualize   Export the identity graph as an interactive HTML visualization

Flags:
  -h, --help   help for graph

Global Flags:
      --config string      Config file path
      --log-level string   Log level (debug, info, warn, error) (default "info")

Use "aether graph [command] --help" for more information about a command.
