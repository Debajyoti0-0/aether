Validate BloodHound attack paths non-destructively and score OPSEC risk.

Usage:
  aether validate [command]

Available Commands:
  path        Validate a BloodHound JSON attack path
  profile     Engagement profile presets (banking, red-team, incident-response, ...)
  risk        Score OPSEC risk for an action
  soc         Predict SOC signals an action will generate
  stealth     Validate the stealth posture of a planned operation

Flags:
  -h, --help   help for validate

Global Flags:
      --config string      Config file path
      --log-level string   Log level (debug, info, warn, error) (default "info")

Use "aether validate [command] --help" for more information about a command.
