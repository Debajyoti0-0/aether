Pivot between cloud and on-prem: extract Kerberos TGTs from cloud tokens (replaces Mimikatz for hybrid).

Usage:
  aether pivot [command]

Available Commands:
  cloud-to-onprem Extract a Kerberos TGT from a cloud token via MS-KKDCP
  imds            Hijack the managed identity of a compromised Azure VM via IMDS
  verify-imds     Verify the full IMDS v2 two-step handshake (PUT token → GET identity)

Flags:
  -h, --help   help for pivot

Global Flags:
      --config string      Config file path
      --log-level string   Log level (debug, info, warn, error) (default "info")

Use "aether pivot [command] --help" for more information about a command.
