RL planner: train, export episodes, generate adaptive plans

Usage:
  aether plan [command]

Available Commands:
  export      Export workspace operations as RL training episodes (vault; --output for JSONL)
  generate    Generate a plan using the trained RL policy
  train       Train the RL planner from exported episodes

Flags:
  -h, --help   help for plan

Global Flags:
      --config string      Config file path
      --log-level string   Log level (debug, info, warn, error) (default "info")

Use "aether plan [command] --help" for more information about a command.
