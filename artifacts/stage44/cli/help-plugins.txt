Plugin registry: search and install community plugins

Usage:
  aether plugins [command]

Available Commands:
  install     Install a plugin from the registry (checksum-verified)
  installed   List locally installed plugins
  search      Search the remote plugin registry

Flags:
  -h, --help           help for plugins
      --index string   Registry index URL (default "https://raw.githubusercontent.com/Debajyoti0-0/aether-plugins/main/index.json")

Global Flags:
      --config string      Config file path
      --log-level string   Log level (debug, info, warn, error) (default "info")

Use "aether plugins [command] --help" for more information about a command.
