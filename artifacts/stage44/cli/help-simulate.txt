Emulate SOC telemetry and log signals (detection engineering)

Usage:
  aether simulate [flags]
  aether simulate [command]

Available Commands:
  fuzz        Generate telemetry variants to test detection rule robustness
  stream      Stream fuzzed telemetry directly into Splunk HEC (governed: audited)

Flags:
      --action string        Action e.g. prt_exchange, wstrust_relay, vm_runcommand (required)
  -h, --help                 help for simulate
      --json                 Output JSON
      --new-device           Sign-in from new device
      --time-of-day string   business_hours or off_hours (default "business_hours")
      --unknown-location     Sign-in from unfamiliar location

Global Flags:
      --config string      Config file path
      --log-level string   Log level (debug, info, warn, error) (default "info")

Use "aether simulate [command] --help" for more information about a command.
