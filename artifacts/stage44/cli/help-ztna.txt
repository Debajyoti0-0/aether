Detect Zero-Trust Network Access gateways (Zscaler, Cloudflare,
Netskope) in the network path and route authentication/execution
through them. Aether doesn't break ZPA — it rides the IdP trust
relationship: tokens issued through the broker's egress originate
from the trusted network location.

Usage:
  aether ztna [command]

Available Commands:
  detect      Detect the ZTNA broker in the network path
  exec        Broker-routed reachability probe of an internal target (does not execute commands)

Flags:
      --browser-preset string   TLS fingerprint preset (default "chrome")
  -h, --help                    help for ztna

Global Flags:
      --config string      Config file path
      --log-level string   Log level (debug, info, warn, error) (default "info")

Use "aether ztna [command] --help" for more information about a command.
