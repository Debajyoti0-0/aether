Poll the environment (graph refresh via --seed graph or provider
export), diff snapshots, and report newly exploitable paths. With
--autopilot, qualifying paths are executed automatically and the
operator is notified through the teamserver.

Usage:
  aether watch [flags]

Flags:
      --autopilot           Automatically execute new paths under the risk ceiling
  -h, --help                help for watch
      --interval duration   Poll interval (default 5m0s)
      --max-risk int        Autopilot risk ceiling (default 40)
      --seed-graph string   Graph JSON to watch (static seed; live providers via future hooks)
      --workspace string    Workspace name (required)

Global Flags:
      --config string      Config file path
      --log-level string   Log level (debug, info, warn, error) (default "info")
