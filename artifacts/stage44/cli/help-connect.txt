Connect to the teamserver as an authenticated operator

Usage:
  aether connect [flags]

Flags:
      --exec string            Execute one command on the teamserver and exit
  -h, --help                   help for connect
      --i-know-what-im-doing   Required confirmation alongside --insecure
      --insecure               Skip server cert verification (research only)
      --operator-cert string   Operator client certificate (PEM; from 'serve cert issue')
      --operator-key string    Operator client key (PEM)
      --server string          Teamserver address (default "127.0.0.1:7788")
      --server-ca string       Teamserver CA certificate to verify the server (default: <operator-cert dir>/teamserver-ca.crt)
      --workspace string       Workspace to sync

Global Flags:
      --config string      Config file path
      --log-level string   Log level (debug, info, warn, error) (default "info")
