Start the mTLS teamserver (cert-bound operators, capability authz, spine dispatch)

Usage:
  aether serve [flags]
  aether serve [command]

Available Commands:
  cert        Teamserver PKI management (CA, operator certificates, revocation)

Flags:
      --ca-cert string         CA certificate PEM used to verify operators (required)
  -h, --help                   help for serve
      --listen string          Listen address (default "127.0.0.1:7788")
      --max-conns int          Maximum concurrent connections (default 32)
      --operators-dir string   Operator capability directory (default: <ca-cert dir>/operators)
      --passphrase string      Workspace passphrase (or AETHER_PASSPHRASE env); required with --workspace
      --revoked string         Revocation list path (default: <ca-cert dir>/revoked.txt)
      --server-cert string     Server certificate PEM (required; from 'serve cert init')
      --server-key string      Server key PEM (required)
      --workspace string       Workspace to attach (remote commands execute through the spine)

Global Flags:
      --config string      Config file path
      --log-level string   Log level (debug, info, warn, error) (default "info")

Use "aether serve [command] --help" for more information about a command.
