Export workspace journals and engagement reports as markdown/SARIF for purple-team workflows.

Usage:
  aether export [command]

Available Commands:
  attck       Export exercised techniques as a MITRE ATT&CK Navigator layer
  audit       Export the signed audit trail as JSONL
  executive   Generate the executive engagement report (KPIs + remediation)
  graph       Export the identity graph topology
  pdf         Export the executive report as a PDF
  prioritize  Prioritize attack paths by CISA KEV exposure (+30% boost)
  report      Export the workspace journal as a markdown report
  sarif       Export path validation results as SARIF

Flags:
  -h, --help   help for export

Global Flags:
      --config string      Config file path
      --log-level string   Log level (debug, info, warn, error) (default "info")

Use "aether export [command] --help" for more information about a command.
