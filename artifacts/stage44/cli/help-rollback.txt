Replay the reverse-action stack recorded during an engagement:
added SP secrets are removed, group memberships reverted, dispatched
pipelines noted. Undo runs newest-first and survives partial failure.

Usage:
  aether rollback [command]

Available Commands:
  list        List recorded reversible actions
  push        Record a reverse action manually
  undo        Undo all recorded actions (newest first)

Flags:
  -h, --help   help for rollback

Global Flags:
      --config string      Config file path
      --log-level string   Log level (debug, info, warn, error) (default "info")

Use "aether rollback [command] --help" for more information about a command.
