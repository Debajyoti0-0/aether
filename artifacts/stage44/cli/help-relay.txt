Relay authentication flows (WS-Trust/SAML, device code) for authorized MFA testing.

Usage:
  aether relay [command]

Available Commands:
  cae-handler     Auto-retry on CAE claims challenges to keep sessions alive
  devicecode      Run a device code flow and poll for tokens
  fido2-downgrade Build and preview a WS-Trust wauth spoof RST (password/SMS class) — not sent
  mex             Parse federation metadata (MEX) and detect downgrade opportunity
  mfa             WS-Trust/SAML relay to OAuth tokens
  saml-strip      Strip ds:Signature elements from a SAML document
  stretch         Keep a session alive via continuous refresh
  ztna            Route the auth relay through the detected ZTNA broker

Flags:
  -h, --help   help for relay

Global Flags:
      --config string      Config file path
      --log-level string   Log level (debug, info, warn, error) (default "info")

Use "aether relay [command] --help" for more information about a command.
