Create, list, report, and securely delete engagement workspaces. All tokens and evidence are AES-256-GCM encrypted at rest (Argon2id key derivation).

Usage:
  aether workspace [command]

Available Commands:
  create      Create a workspace
  delete      Securely delete a workspace (shred + remove)
  info        Show workspace details
  list        List workspaces
  rekey       Rotate the workspace encryption passphrase
  report      Generate the workspace engagement report

Flags:
  -h, --help   help for workspace

Global Flags:
      --config string      Config file path
      --log-level string   Log level (debug, info, warn, error) (default "info")

Use "aether workspace [command] --help" for more information about a command.
